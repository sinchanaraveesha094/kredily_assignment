# Kredily Assignment

This repository contains my QA testing assignment for Kredily. It covers manual testing, bug reporting, mobile automation testing, and API testing.

## Description
This assignment demonstrates my skills in software testing across different areas:

- **Manual Testing:** Test cases were written and executed to verify the application's features, functionality, and user flows.
- **Bug Report:** Defects found during testing are documented with steps to reproduce, expected result, actual result, severity, and screenshots.
- **Mobile Automation:** Automated test scripts were created to test the mobile application and verify key user actions.
- **API Testing:** The application's APIs were tested by sending requests and validating the responses, status codes, and data.

## Contents
- Manual test cases
- Bug report
- Mobile automation scripts
- API test collection and results

## Tools Used
- Manual testing: Excel / Google Sheets
- Bug tracking: Excel / Google Sheets
- Mobile automation: Appium
- API testing: Postman

## How to Run
1. Download or clone this repository
2. Open the project folder on your computer
3. For manual testing and bug report: open the files in Excel or Google Sheets
4. For API testing: import the Postman collection into Postman and run it
5. For mobile automation: set up Appium, connect a device or emulator, and run the test scripts
